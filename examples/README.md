# Example data for real testing

This folder contains sample data that can be used immediately with the project.

Files:
- `kb.json`: example knowledge base with SOPs, sensor layout, accepted room windows, and product criticality.
- `production_plan.csv`: example daily production plan.

You can run the software with the bundled example data using:

```bash
deviation-risk-generator
```

When prompted, enter a sensor and trend image filename, such as:
- Sensor: `BMS-101`
- Trend image: `trend_20260923_1330.png`
